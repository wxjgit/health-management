# 轻记微信小程序

项目唯一前端，基于 Taro + React + TypeScript。Web 工程及后端静态页面托管已移除。API 类型在 `src/types.ts` 独立维护。

## 开发

要求 Node.js 22.12+，先启动根目录的 Python API 服务，再运行：

```sh
npm ci
npm test
npm run typecheck
npm run build:weapp
```

微信开发者工具导入本目录，使用自己的 AppID。监听编译使用 `npm run dev:weapp`，构建产物在 `dist/`。该目录不需要由后端或网站服务器托管。Taro 已编译 JavaScript，项目的 `es6` 与 `enhance` 均关闭，与 Taro 官方模板一致。

「我的 → 开发服务配置」填写 API 地址（不带 `/api`）。开发者工具默认连接 `http://127.0.0.1:8000`，真机使用可达的可信测试网络地址。后端绑定地址需按联调网络配置，现有服务无鉴权，不能直接暴露公网。

## 页面

- 记录：自然语言记录、跨天补记、纠错、选择追问、选项回答、流程取消与恢复、来源与执行摘要。
- 今日：营养汇总、未知项、当前目标及差额、体重睡眠运动、饮食完整标记。
- 历史：类型/日期/关键词筛选、28天体重与睡眠趋势、修订差异、纠错、删除预览、月度摘要。
- 计划：默认估算与依据、手动目标、一周安排、计划确认/拒绝/取消、失败恢复。
- 发现：规律及限制、认可/否认、日周复盘和证据跳转。
- 我的：档案、长期信息及冲突选择、权重提醒、通知、JSON 文件导出与分享、隐私删除恢复。

请求结果不确定时在设备保存一份原请求，重试沿用同一业务编号；未核对前禁止其他写入和切换服务。缓存可能包含健康原文，请勿把设备存储导出当作无敏感日志。服务器恢复的补充请求始终沿用原参数，纯本地偏好不会静默允许模型重试。

删除前展示实际范围，范围变化必须再次确认；未完成作业保存编号以供恢复。删除会失效所有页面内存并清理应用内导出文件，已分享的外部副本需要自行删除。

## 验收与上线

构建和单元测试不能代替微信开发者工具、真机键盘/安全区域/文件分享/切后台验收。正式发布需配置真实 AppID、HTTPS 合法域名、开启域名校验、服务端鉴权及隐私声明。多人使用还需后端全链路数据隔离。微信订阅消息属于新能力，当前继续采用站内消息。

完整设计见 [微信小程序开发方案](../docs/微信小程序开发方案.md)。

## 编译服务异常排查

若出现 `[Builder Services] getRootFactory Not Define Env Error`，这是开发者工具编译服务尚未初始化环境时抛出的异常，不能据此判断业务有死循环。2026-10-27 在工具 2.02.2609240 的实际安装代码中确认了此抛错条件；当前所有页面 WXML 使用该工具自带的原生 `wcc` 独立编译通过。

先结束真机调试，完整退出开发者工具（macOS 使用 Cmd+Q），重新启动并打开 `miniprogram/` 工程，清理编译缓存后重新编译。不要清理数据缓存，设备中可能保存待重试请求和删除作业编号。如果重启后仍出现同一工具内部堆栈，需要继续通过官方诊断接口检查编译服务或更换经验证的工具版本；Taro 构建通过不等于开发者工具已经恢复。
