# 轻记微信小程序

微信原生小程序，全部 11 个页面使用 `Page` / `Component`、WXML、WXSS 和 `wx`。
按钮、空状态、图标和底部液态玻璃导航使用 PyUI 原生组件；业务数据仍由 Python API 提供。
运行与构建均不依赖 Taro、React 或 webpack。

## 开发

要求 Node.js 22.12+。先按根目录文档配置并启动 Python API，再运行：

```sh
npm ci
npm run typecheck
npm test
npm run build:weapp:dev
```

微信开发者工具导入 `miniprogram/`，项目小程序根目录保持 `dist/`。
日常编辑 `native/`，运行 `npm run dev:weapp` 监听修改；无需在开发者工具中构建 npm。
`typecheck` 检查编辑器契约、测试类型、JavaScript 语法、组件四件套、引用和事件绑定。
JavaScript 页面动态数据另由原生页面行为测试覆盖。

正式构建前设置 `MINIPROGRAM_API_ORIGIN` 为不带路径、端口或凭据的 HTTPS 域名，再运行 `npm run build:weapp`。
正式包固定使用构建地址；开发构建可读取设备中的 `api-base`，默认为 `http://127.0.0.1:8000`。
真机联调应在开发构建前填写手机可访问的地址。本机端口不指向手机所在电脑。

构建脚本只复制原生文件并生成服务地址配置。生产依赖为空；TypeScript、Vitest/Vite 和 Prettier 仅用于本地检查、测试和格式化。

## 页面

- 记录：自然语言记录、跨天补记、选择追问、纠错、问答取消与恢复、分页、证据跳转；今日状态通过弹窗查看。
- 足迹：体重/睡眠/运动趋势、按日查看记录、修订差异、纠错、删除预览入口和月度摘要。
- 复盘：功能待上线占位。
- 我的：当前生效计划七项摘要、更改计划和个人档案弹窗、长期信息、偏好提醒、站内消息、隐私管理及账号操作。
- 登录与授权：必要隐私/健康授权、可选模型授权、授权撤回。
- 隐私清理：实际范围预览、再次确认、范围变化停止旧请求、作业查询与继续清理。

请求结果不确定时在设备保存原请求，重试沿用业务编号；未核对前禁止其他写入。
待处理请求和删除作业按账号隔离。账号或服务变化会拒绝旧响应，不将上个账号的数据写回当前页面。
隐私删除会使所有缓存页面失效，并清理应用内导出文件；已经分享的外部副本需自行删除。
